# Ubunono Holdings website

This is the editable GitHub Pages version of the Ubunono Holdings website.

## Edit the website

- Change page wording and contact details in `index.html`.
- Change colours, spacing, sizing and layout in `style.css`.
- Change the portfolio order or captions in the `projects` list at the top of `script.js`.
- Replace an image in `assets` while keeping the same filename, or update its filename in the relevant HTML/JavaScript file.

## Publish free with GitHub Pages

1. Create a new public GitHub repository, for example `ubunono-horticulture`.
2. Extract this ZIP and upload everything inside the `ubunono-github-pages` folder to the repository root.
3. Open the repository's **Settings**.
4. Select **Pages** under **Code and automation**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then select **Save**.
7. After deployment, GitHub will display the free website address. It normally follows this format:
   `https://YOUR-GITHUB-NAME.github.io/ubunono-horticulture/`

## Optional custom domain

GitHub Pages hosting remains free when using a purchased custom domain. To use `ubunono-horticulture.site`, purchase that domain first and then enter it under **Settings → Pages → Custom domain**. The domain registrar's DNS records must then be connected to GitHub Pages.
